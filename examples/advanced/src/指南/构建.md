# 构建流程

## 完整构建

首次构建生成页面、主题、脚本和搜索索引。

```bash
moon run --target native cmd/main -- build examples/advanced
```

## 增量构建

MoonBook 在输出目录保存 `.moonbook-manifest`。章节输入、配置、目录或模板没有变化时，会直接跳过渲染。

## 资源管线

- 章节源目录中的非 Markdown 文件保持相对路径复制；
- `static-dir` 中的文件复制到站点根目录；
- 附加 CSS 和 JavaScript 自动写入页面；
- 缺失的本地资源会导致检查失败。
